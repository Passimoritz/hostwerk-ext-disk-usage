# Moved → [Drives (`disk-health`)](https://github.com/Passimoritz/hostwerk-ext-disk-health)

**“Storage per service” is now part of the extension [“Drives” (`disk-health`)](https://github.com/Passimoritz/hostwerk-ext-disk-health)** – used space per service, history and forecast, plus every file sorted by service under **System → Storage**.

Hostwerk installs “Drives” by itself, takes the history over and removes this extension. Nothing to do on your side.
