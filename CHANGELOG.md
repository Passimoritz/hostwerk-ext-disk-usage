## 1.3.0

- Game servers and Docker volumes count along (Hostwerk 3.0 sends them): their own names and parts (“Docker volume”), the folder button opens the game server or the Docker app the volume belongs to. / Spiele-Server und Docker-Volumes zählen mit: eigene Namen und Teile, der Ordner-Knopf öffnet den Spiele-Server bzw. die Docker-App.
- Filter by kind above the list with the space per kind (Minecraft, game servers, Docker …). / Filter nach Art über der Liste mit dem Platz je Art.

## 1.2.0

- History and forecast: drive usage noted hourly, growth per day and “full in about X days”. / Verlauf und Prognose: Belegung stündlich notiert, Zuwachs pro Tag und „voll in etwa X Tagen“.
- Free up space: large backups and a full drive with a button to the right place. / Platz schaffen: große Sicherungen und volles Laufwerk mit Knopf zur richtigen Stelle.
- Folder button per service opens its files. / Ordner-Knopf je Dienst öffnet seine Dateien.
- Share of the total shown per service; bars as `role="meter"` for screen readers. / Anteil am Gesamtplatz je Dienst sichtbar; Balken als `role="meter"` für Bildschirmleser.
- Loading errors with “Try again” on page and tile; no recounting while hidden; time in Hostwerk's language; design scale instead of fixed pixels. / Ladefehler mit „Erneut versuchen“ auf Seite und Kachel; kein Nachzählen bei verstecktem Reiter; Uhrzeit in Hostwerks Sprache; Design-Skala statt fester Pixel.
- Sidebar: next to System (`page.nav`); other extensions may add tabs (`allowExtensions`); labels for game servers and Docker volumes. / Seitenleiste: neben System (`page.nav`); andere Erweiterungen dürfen Reiter ergänzen (`allowExtensions`); Bezeichnungen für Spiele-Server und Docker-Volumes.
- Release package contains everything except the repository tooling. / Release-Paket enthält alles außer dem Repo-Werkzeug.
