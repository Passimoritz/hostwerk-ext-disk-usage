# Umgezogen → [Laufwerke (`disk-health`)](https://github.com/Passimoritz/hostwerk-ext-disk-health)

**„Speicher je Dienst“ ist jetzt Teil der Erweiterung [„Laufwerke“ (`disk-health`)](https://github.com/Passimoritz/hostwerk-ext-disk-health)** – Belegung je Dienst, Verlauf und Prognose, dazu alle Dateien nach Dienst sortiert unter **System → Speicher**.

Hostwerk installiert „Laufwerke“ von selbst, übernimmt den Verlauf und entfernt diese Erweiterung. Du musst nichts tun.
